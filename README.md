# Трек

Личный трекер подготовки: задачи на каждый день, переносы, «Хвосты», сдвиг плана, паузы.
Открывается как приложение на телефоне и ноутбуке, работает без интернета.

Планы в папке `plans/` зашифрованы (AES-256-GCM, ключ из пароля через PBKDF2-SHA256, 600 000 итераций), имена файлов — хеши.
Прогресс хранится на устройстве и, если включить, в приватном Gist владельца — тоже зашифрованным.

Сменить пароль: `pip install cryptography`, затем `python3 tools/set_password.py`.
